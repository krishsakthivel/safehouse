# Safehouse

> **Know where a link goes before you click.**

Safehouse is a web-based security analysis platform that inspects suspicious URLs and files using threat intelligence, sandbox analysis, metadata extraction, and AI-powered explanations.

Rather than opening an unknown website in your own browser, Safehouse gathers intelligence from trusted security services and presents a clear, human-readable risk assessment.

---

## Features

### URL Analysis

- Redirect chain inspection
- Destination URL verification
- Page intelligence collection
- VirusTotal integration
- urlscan.io sandbox analysis
- Safe website screenshots
- AI-powered threat summaries
- Risk scoring and recommendations

### File Analysis

Analyze common file formats including:

- Images
- PDFs
- Microsoft Office documents
- Audio files
- Video files

Extracts:

- File metadata
- EXIF information
- Document properties
- AI-assisted security observations

## Security Philosophy

Safehouse is built around one simple idea:

> **Don't visit an unknown site until you've inspected it first.**

By combining multiple intelligence sources with AI-powered explanations, Safehouse helps users make informed decisions before interacting with potentially malicious content.
